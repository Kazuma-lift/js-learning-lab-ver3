（1）制作アプリのタイトル

「JavaScript Learning Lab｜Ver.3」

（2）制作アプリの説明（40文字程度）

JavaScript初心者が、アプリの操作を通してコードの処理過程を視覚的に学べるWebアプリ。

・画面左側でアプリを操作すると、右側にJavaScriptの実行コード・変数の変化・処理ログ・解説が段階的に表示される。

・Ver.2のじゃんけんとタスク管理に加え、Ver.3ではタスクの追加と完了状態をブラウザに保存する。再読み込み後も同じ一覧を復元できる。

・保存には localStorage と JSON.stringify() / JSON.parse() を使い、配列とJSON文字列の違いを学習パネルで確認できる。

・コードを自分で読み解き、処理の仕組みや妥当性を理解して、AIに適切な修正指示を出せるようになることを目指す。

（3）前回Verからの変更点

・保存のタイミング： 保存ボタンは追加せず、タスクの追加と完了・未完了の切り替えの直後に、最新の配列を保存するようにした。

・復元と削除： ページを開いたときに保存データがあれば一覧を復元し、無いときは初期の4件を表示する。リセットでは一覧を空にし、保存データも削除する。再読み込みすると初期の4件に戻る。

・動作改定：タスク管理では、操作のたびにステップを自動で送らない。結果はすぐに画面へ出し、続きは「1つ進む」か「再生」で進める。じゃんけんは従来どおり2秒間隔。

・実行ログ： タスク管理の実行ログの記録を押すと、その時点の実行コード・変数・解説へ移れる。前の操作の記録も見返せる。じゃんけんは従来通りの仕様を維持。

（4）難しかった点・次回トライしたいこと（または機能）

・コードと解説の整合性： コード一覧の説明と、実際に動く保存・復元のコードがずれないようにすること。
